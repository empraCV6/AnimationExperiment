## AnimationExperiment 製作理由
本プログラムは、前回製作したレースゲーム風技術デモで学んだ設計や構成の復習を目的としつつ、
SFMLを用いたスプライトアニメーションの管理・遷移処理を検証する技術デモとして作成しました。
## 意識した点
アニメーション処理を Animation クラスとして独立させ、
プレイヤー以外のオブジェクトにも流用可能な構成を意識しました。
また、前作で使用した GameContext の設計を踏襲し、
将来的にシーン追加やオブジェクト増加を行うことを前提とした拡張性のある構成を目指しました。
## 反省点
アニメーションの技術検証が主目的であるにもかかわらず前作技術の復習も兼ねて製作したため、不必要なシステムや回りくどい作りが目立ちました。
また、まだクラス設計が甘いため、プレイヤークラスへの過度な責任付与もあったと思います。
次回以降の製作ではクラスへの役割分担にももっと意識を回そうと思います。
